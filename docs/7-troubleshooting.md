# 🩹 Troubleshooting

The problems people meet, and their fixes. Every error Go Engine reports has a **code**, as
`engine.scene-not-found`: search this page for it.

## Common problems

**`go install` fails with "cgo" or "gcc".** The editor's window needs a C compiler and OpenGL's
headers. On Debian or Ubuntu: `sudo apt install gcc libgl1-mesa-dev xorg-dev libwayland-dev libxkbcommon-dev`. On macOS:
`xcode-select --install`.

**The editor opens, but a behaviour is "Not in the project's code (yet?)".** The editor runs inside
your game, so new code needs **Rebuild** (in Code). If it still shows, the behaviour is not
registered: add it to `engine.Register(…)` in `main.go`.

**A behaviour's field does not change anything.** The scene fills exported fields by their JSON
name: check the tag, as `` `json:"speed"` ``, and that the field starts with a capital letter.

**The player falls through the ground.** Its body must be **Moving** and the ground's **Solid**, or
the tiles must be solid in the tileset (in **Art**, tinted blue). **Bodies**, over the view, shows
both.

**A node moves in the editor but jumps back when played.** Move bodies by their velocity, never
by their transform, while the game plays.

**Lights do nothing.** In 2D, check **Lit** over the view is on. A light reaches only its outer
radius: **Lights** draws it. On the 3DS, a 3D lamp lights a floor only where it has vertices.

**The 3DS build fails.** **Build → Tools** checks each tool: TinyGo must be TinyGo for the 3DS
(its own TinyGo has no `nintendo3ds` target), and devkitPro needs its `3ds-dev` packages.

**Send finds no console.** Open the Homebrew Launcher and press Y before **Send**. If the network
hides the console, set its address in **Project → Settings**.
