# Contributing to Go Engine

Thank you for wanting to help. How the code is laid out, how to build and test it, and how a change
is proposed are in [docs/8-contributing/1-contributing.md](docs/8-contributing/1-contributing.md);
how the code is written is in the [style guide](docs/8-contributing/2-style-guide.md).

In short: `go vet ./...` and `go test ./...` pass before a pull request, every change in behaviour
comes with its test and its docs, and anything larger than a fix starts as a proposal in
[docs/proposals](docs/proposals/).

Found a bug, or have an idea? Open an issue: the templates ask for what helps.
