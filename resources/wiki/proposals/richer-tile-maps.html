10. Richer tile maps: several tilesets, turned tiles, tiles solid in part

Status: proposed · Author’s approval: proposal ☐ plan ☐

Why

Making io-world (proposal 7) found three limits of tile maps:

  • A tile map takes one tileset. Godot’s tile set mixes pictures, so one level became two tile maps, painted apart.
  • Tiles cannot be mirrored or turned. io-world’s flipped tiles are drawn unflipped, and an artist draws every corner four times.
  • A solid tile is solid all over. io-world’s attractor tiles are solid only in part, here whole squares.

Tiled and Godot both solve the first two the same way, and the third with a shape per tile.

Out of scope

  • Slopes and shapes other than boxes: the physics only has boxes (see proposal 1).
  • Animated tiles (water that ripples). A sprite does it for now.
  • Tiles painted by rules (autotiling): a later proposal.

Design

Several tilesets, as Tiled does it. A tile map lists tilesets, in order. Tile numbers run through them: the first tileset’s tiles come first, then the second’s. A map with one tileset keeps working (R4). The palette has a tab per tileset.

Turned tiles: a tile map gains turns, a number per cell from 0 to 7. Its three bits are mirror across, mirror up and down, and swap the axes, as Tiled’s. Absent means none. When a map loads, each turned tile used gets its own picture, made once, as mirrored sprites are. Drawing stays one picture per cell (R5). In Level, X, Y and Z turn the tile being painted.

Solid in part: a tileset’s solid stays a list of whole tiles. A new boxes maps a tile number to a box in pixels inside it. Merging rows into one body only joins whole tiles; a part box is a body of its own. Art draws the box over the tile, and dragging changes it. A turned tile turns its box too.

Alternatives not taken:

  • A layer per tileset (several tile maps under one node). It is what io-world does now, and painting means switching nodes all the time.
  • Turn bits inside the tile number, as Tiled’s files do. That is compact, but unreadable in a scene file a person opens.
