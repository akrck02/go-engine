🩹 Troubleshooting

The problems people meet, and their fixes. Every error Go Engine reports has a code, as engine.scene-not-found: search this page for it.

Common problems

go install fails with “cgo” or “gcc”. The editor’s window needs a C compiler and OpenGL’s headers. On Debian or Ubuntu: sudo apt install gcc libgl1-mesa-dev xorg-dev libwayland-dev libxkbcommon-dev. On macOS: xcode-select --install.

The editor opens, but a behaviour is “Not in the project’s code (yet?)”. The editor runs inside your game, so new code needs Rebuild (in Code). If it still shows, the behaviour is not registered: add it to engine.Register(…) in main.go.

A behaviour’s field does not change anything. The scene fills exported fields by their JSON name: check the tag, as `json:"speed"`, and that the field starts with a capital letter.

The player falls through the ground. Its body must be Moving and the ground’s Solid, or the tiles must be solid in the tileset (in Art, tinted blue). Bodies, over the view, shows both.

A node moves in the editor but jumps back when played. Move bodies by their velocity, never by their transform, while the game plays.

Lights do nothing. In 2D, check Lit over the view is on. A light reaches only its outer radius: Lights draws it. On the 3DS, a 3D lamp lights a floor only where it has vertices.

The 3DS build fails. Build → Tools checks each tool: TinyGo must be TinyGo for the 3DS (its own TinyGo has no nintendo3ds target), and devkitPro needs its 3ds-dev packages.

Send finds no console. Open the Homebrew Launcher and press Y before Send. If the network hides the console, set its address in Project → Settings.

Every error code

Code What happened, and what to do
build.3dslink-not-found sending to the 3DS needs devkitPro’s 3dslink (the 3ds-dev package): install it or set its folder in Build’s tools, or $DEVKITPRO
build.adb-not-found playing on an Android device needs adb, the SDK’s platform-tools
build.android-ndk-incomplete the Android NDK has no compilers for this system: install another version of it
build.android-ndk-not-found building for Android needs the Android NDK, in the SDK’s ndk folder (Android Studio’s SDK Manager): install it or set its place in Build’s tools, or $ANDROID_NDK_HOME
build.android-sdk-incomplete the Android SDK lacks parts a build needs: install them with its SDK Manager, or Install
build.android-sdk-not-found building for Android needs the Android SDK (Android Studio installs it): install it or set its place in Build’s tools, or $ANDROID_HOME
build.console-emulator-not-found no 3DS emulator found (azahar, lime3ds, citra-qt or citra): install it or set its place in Build’s tools, or put one on the path
build.devkitpro-incomplete devkitPro lacks parts of the 3DS’s: install its 3ds-dev packages (Install runs devkitPro’s installer)
build.java-not-found Android’s builds need a JDK (17 or newer, as Adoptium’s Temurin, or Android Studio’s): install one or set its folder in Build’s tools, or $JAVA_HOME
build.java-without-compiler the Java found is only a runtime, with no javac: Android’s builds need a JDK
build.source-not-found go-engine’s source, which programs build against, is not where the editor was built
build.tinygo-not-found building for the 3DS needs TinyGo with the nintendo3ds target (github.com/akrck02/tinygo-3ds): install it or set its place in Build’s tools, or $TINYGO
build.tinygo-without-console the TinyGo found has no nintendo3ds target: it is not tinygo-3ds’s (Install gets it)
build.tool-failed a Go tool failed
build.tool-place-wrong nothing is where the tool was set: change it in Build’s tools, or empty it to look for the tool
build.tools-not-read the tools’ places kept on this computer could not be read
build.tools-not-saved the tools’ places could not be kept on this computer
editor.art-not-found the sprite or tileset is not a file of the project’s
editor.art-not-saved the sprite or tileset could not be written
editor.art-unsaved the sprite or tileset open in Art has changes not saved: save it first
editor.art-wrong-kind the file is not a sprite’s or a tileset’s
editor.frames-wrong an animation’s frames are not numbers and runs of the sheet’s frames, as 0-3, 6
editor.no-own-sheet the node does not cut its picture into frames itself
editor.restart-failed the editor could not start again with the project’s new code
editor.tools-in-use the tools cannot change while the game builds or plays: wait for it to end, or stop it
editor.unsaved-changes the scene has changes not saved: save it first (Ctrl+S)
engine.behaviour-fields the scene’s fields do not fit the behaviour’s
engine.behaviour-unregistered no behaviour is registered by that name (engine.Register in the game’s main)
engine.model-format only .glb models are read for now
engine.model-not-found the model’s file does not exist
engine.model-unreadable the model’s file is not a .glb go-renderer reads
engine.no-files the scene was made without the project’s files
engine.no-start-scene engine.json names no start scene
engine.picture-not-found the picture’s file does not exist
engine.picture-unreadable the picture is not a PNG or a JPEG
engine.scene-not-found the scene file does not exist
engine.scene-not-restartable the scene was not made from a description, so it cannot start again
engine.scene-unreadable the scene file is not a scene
engine.settings-not-found the project has no engine.json
engine.settings-unreadable engine.json is not the project’s settings
engine.sprite-not-found the sprite’s file does not exist
engine.tileset-not-found the tileset’s file does not exist
go-engine.missing-folder usage: go-engine new [name]
install.android-manager-failed Android’s sdkmanager could not install the packages
install.checksum-wrong the file downloaded is not the one published (its checksum differs): it was not used
install.data-folder-not-found the folder for the user’s data could not be found
install.download-failed the file could not be downloaded: check the network, and try again
install.java-not-found Android’s tools need a JDK, and none was given

project.engine-not-updated go-engine could not be updated: check the network, and that the version exists
project.folder-not-empty a new project needs an empty folder
project.import-failed the file could not be copied into the project
project.import-format only .glb models can be imported for now (export glTF as binary .glb)
project.no-android-device adb sees no Android device: plug a phone in with USB debugging on, or start the emulator
project.not-a-project the folder is not a go-engine project; make one with: go-engine new

project.settings-not-saved engine.json could not be written
project.terminal-not-found the code editor runs in a terminal, and no terminal was found

scenefile.light-radii-wrong a light’s radii are below zero, or the inner one is beyond the outer
scenefile.no-picture a sprite or a tileset names no picture
scenefile.node-without-name a node has no name
scenefile.same-animation-name two animations of a sheet have the same name
scenefile.same-name two nodes under the same parent have the same name

scenefile.slash-in-name a node’s name has a slash, which separates the names of a path

scenefile.unknown-animation a sheet starts with an animation it does not have
scenefile.unknown-body-kind a body’s kind is not one of BodyKinds
