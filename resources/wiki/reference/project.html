project

import "github.com/akrck02/go-engine/project"

Package project is a game made with go-engine, as a folder: a Go module whose main runs the engine, the game’s own Go code beside it, its scenes in scenes/ and what it imports in assets/. It is an ordinary Go module, so any editor with Go’s language server (Zed, Neovim, Visual Studio Code, GoLand…) edits the code, and go run . plays it.

Behaviour is a behaviour the project’s code defines: a struct type with one of the methods the engine calls (behaviourMethods), as the editor offers it.

Project

Project is a game’s folder.

type Project struct {
	Folder   string
	Settings engine.Settings
	// Tools are the places of the tools that build for consoles and phones, kept on this
	// computer for every project.
	Tools build.Tools
	// ToolsUnread is why the places kept could not be read, when they could not: the builds look
	// for the tools as if none were kept, and saving writes them anew.
	ToolsUnread error
}
