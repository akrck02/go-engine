project

import "github.com/akrck02/go-engine/project"

Package project is a game made with go-engine, as a folder: a Go module whose main runs the engine, the game’s own Go code beside it, its scenes in scenes/ and what it imports in assets/. It is an ordinary Go module, so any editor with Go’s language server (Zed, Neovim, Visual Studio Code, GoLand…) edits the code, and go run . plays it.

type Project struct {
	Folder   string

	// for the tools as if none were kept, and saving writes them anew.
	ToolsUnread error
}
