engine

import "github.com/akrck02/go-engine/engine"

Package engine runs a game: a scene of nodes, read from the project’s scene files, drawn by go-renderer, and moved by the game’s own Go code through behaviours. A node is a thing in the world: a shape, a model, a sprite, a camera, or an empty point to hang others from. Its Transform places it relative to its parent, in metres and degrees (see package space).

A game’s main registers its behaviours and runs the project it embeds:
