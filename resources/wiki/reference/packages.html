📚 The reference

Every public package of Go Engine, generated from its doc comments by generate.py, and the files a project is made of. Look names up here; learn them in the guides.

For a game’s code

Package What it is for
engine The running game: nodes, scenes, behaviours, the context, input, cameras, Run
space Vectors, rotations, angles, transforms and boxes, in metres
animation Tweens of numbers, vectors and rotations, with easings, loops and chains
physics The 2D physics: bodies, their kinds, gravity and zones
scenefile The scene, sprite and tileset files: read, write, check
shapes The meshes of the shapes, a metre across
failure Error codes, which every error the engine returns carries

For tools

Package What it is for
project A project’s folder: create, import, build, find its behaviours
editor The editor, which a game installs in itself while it is made

The files

The project’s files: engine.json, scenes, sprites and tilesets, key by key.
